\# DonorKu



Aplikasi mobile Flutter untuk menghubungkan orang yang membutuhkan darah

dengan pendonor yang tepat berdasarkan golongan darah, lokasi, dan

kelayakan donor.



\## Masalah

Permintaan darah darurat umumnya disebar lewat grup chat dan media sosial,

sehingga sulit menemukan pendonor yang cocok, dekat, dan layak, serta

rawan informasi yang tidak terverifikasi.



\## Role

Pendonor, Pemohon, dan Admin (verifikator).



\## Teknologi

Flutter, Laravel (REST API + Sanctum), MySQL.



\## Struktur

\- `backend/` API Laravel

\- `mobile/` aplikasi Flutter

\- `docs/` rancangan dan dokumentasi
